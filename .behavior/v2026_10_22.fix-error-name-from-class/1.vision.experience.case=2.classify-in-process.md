# case 2 — a consumer classifies in process

happy · critipath · actor: consumer who classifies in process · class: all three

## narrative

a sign-in screen catches an error from its auth sdk and must decide whether to show "invalid phone". it checks `error instanceof WhodisBadRequestError`. the check is exact, follows inheritance, and survives a minifier. `error.name` reads `'Error'` the whole time, and the screen never looks at it.

## bdd

- `[t0]` given a thrown `QuoteExpiredError extends ConstraintError`
  - when the consumer checks `error instanceof ConstraintError`
  - then it is true
- `[t1]` given the same error from a duplicate copy of helpful-errors
  - when the consumer calls `isHelpfulError(error)`
  - then it is true, though `instanceof` across copies may not be
- `[t2]` given any HelpfulError
  - when the consumer reads `error.name`
  - then it reads `'Error'`, which carries no class

# case=3 — base class names itself

feel: happy · care: critipath

## narrative

a caller throws a plain `new HelpfulError('could not get joke', { why })` from a lambda. its name reads `HelpfulError` on every reader — the wire `errorType`, the log text header, the json log — consistent with every subclass. the message keeps no prefix, as today. on the wire, `HelpfulError` maps to a server fault, which matches what a base HelpfulError means: no caller fault was declared.

## [tn] timeline

- [t0] given `new HelpfulError('could not get joke')`
- [t1] when the caller reads `.name`
  - then it reads `'HelpfulError'` (was `'Error'`)
  - then `.message` is unchanged: `'could not get joke'`
- [t2] when a lambda throws it and the runtime serializes the throw
  - then `errorType` = `'HelpfulError'` — a server fault, as before, now named
- [t3] when logged via `String(error)` and `JSON.stringify(error)`
  - then the header opens with `'HelpfulError: '` and the json has `"name":"HelpfulError"`

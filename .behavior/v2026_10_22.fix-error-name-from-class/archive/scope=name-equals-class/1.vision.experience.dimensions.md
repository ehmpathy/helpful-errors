# 1.vision.experience.dimensions

## axes

| axis | positions | what varies |
|---|---|---|
| class | `HelpfulError` (base) · built-in, caller-fault lineage (`ConstraintError`, `BadRequestError`) · built-in, server-fault lineage (`MalfunctionError`, `UnexpectedCodePathError`) · user subclass of a caller-fault class (`extends ConstraintError` / `BadRequestError`) · user subclass of a server-fault class (`extends HelpfulError` / `MalfunctionError` / `UnexpectedCodePathError`) · user subclass that sets its own `name` | which `new.target` the constructor sees; which fault the class means; whether a later write overrides the name |
| reader | wire (`{ errorType: error.name }` → client / sqs) · runtime branch (`error.name === …` in prod code) · log text (`String(error)` / `stack` header) · json log (`JSON.stringify`) · jest snapshot (`[Name: msg]`) | which surface reads `name`, and who acts on it |
| bundle | names kept (unminified, or minified with `--keep-names`) · names mangled (minified without `--keep-names`) | whether `new.target.name` equals the source class name |

## orthogonality

- **class ⟂ reader** — every class reaches every reader: any HelpfulError may be thrown in a lambda, branched on, logged, json-logged, or snapshotted. no class value implies a reader value
- **class ⟂ bundle**, with one exception — a bundler mangles the class identifier of base, built-in, and plain user classes alike. the exception: a user subclass that sets its own `name` sets a string literal, which a minifier does not touch, so that class value is bundle-invariant. the inventory records it as such rather than as a mangled cell
- **reader ⟂ bundle** — a mangled name reaches every reader the same way
- actor folds into reader: each actor is defined by the surface it reads (lambda client ↔ wire, on-call ↔ log text, test author ↔ snapshot), so a separate actor axis would duplicate reader
- user subclass splits by lineage: the wire outcome differs (a caller-fault lineage subclass misses the client's exact-name map; a server-fault lineage subclass reads a server fault, as it should)

## collapses, justified

- **built-ins within one lineage** are one value: `BadRequestError`, `UnexpectedCodePathError`, `ConstraintError`, `MalfunctionError` declare no constructor, only static `code` / `emoji` (`src/*Error.ts`), so all four run the identical base constructor path. they split only by lineage, since the wire classifies caller vs server fault by name
- **construction** (`new` · `.throw()` · `.wrap()` · `.redact()`) is not an axis: every path constructs with `new.target` = the subclass — `.throw()` runs `new this(...)` (`src/HelpfulError.ts:198`), `.wrap()` passes `variant: this` into `withHelpfulError`, which runs `new Constructor(...)` (`:245-247`, `:373-389`), `.redact()` runs `new this.constructor(...)` (`:288`)
- **names kept** folds unminified and `--keep-names`: both preserve `Function.name`, so `new.target.name` reads the source name in each

## forbidden / impossible cells

none forbidden. every class × reader × bundle cell is reachable by nature; no invariant bars one. the own-`name` × names-mangled cells are reachable but identical to own-`name` × names-kept, since the literal survives minification.

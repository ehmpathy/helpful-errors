# case=6 — consumer snapshot shifts on upgrade

feel: sharp · care: critipath

## narrative

a consumer bumps helpful-errors. a jest snapshot that pinned `[Error: ✋ ConstraintError: email must be valid]` now renders `[ConstraintError: ✋ ConstraintError: email must be valid]`, and a json snapshot gains a `"name"` key. the test fails loud, at once, with a diff that shows exactly the one changed token. the release notes (PR body) name the shift, so the fix is `--updateSnapshot`, not a debug session.

## fail-safe

- fast: fails on the first test run after the bump
- loud: a jest snapshot diff, never a silent pass
- teaches the fix: the PR body lists each snapshot shape that changed and why

## [tn] timeline

- [t0] given a consumer test with `expect(error).toMatchSnapshot()` pinned under the old version
- [t1] when the consumer upgrades and runs tests
  - then the snapshot fails with diff `- [Error: …` / `+ [ConstraintError: …`
- [t2] when the consumer reads the release notes and resnaps
  - then the test passes, and the snapshot now names the class

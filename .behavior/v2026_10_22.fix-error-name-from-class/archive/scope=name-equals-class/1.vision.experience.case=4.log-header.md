# case=4 — on-call reads the log header

feel: happy · care: critipath

## narrative

at 3am an on-call engineer scans a log of uncaught errors. each stack header used to open with `Error:`, so the class hid inside the message. now each header opens with the class — `MalfunctionError: 💥 MalfunctionError: db conn lost` — and a grep on `^MalfunctionError` finds them.

## [tn] timeline

- [t0] given `new MalfunctionError('db conn lost')`
- [t1] when the logger prints `String(error)` or `error.stack`
  - then the first line opens with `'MalfunctionError: '` (was `'Error: '`)
  - then the class name appears twice in that line, since the message keeps its prefix (fulcrum F2)

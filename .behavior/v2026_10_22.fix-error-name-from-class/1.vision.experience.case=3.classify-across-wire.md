# case 3 — a producer classifies across a wire

happy · critipath · actor: producer who classifies across a wire · class: all three, consumer subclass the sharpest

## narrative

a lambda endpoint built with sdk-aws-lambda's `genLambdaEndpoint` throws a `QuoteExpiredError`. before the error leaves the process, `genConstraintErrorMiddleware` asks `getIsConstraintError({ error })`, which checks `instanceof ConstraintError` / `BadRequestError` first, and gets yes. (its later `name` and constructor-name fallbacks serve rehydrated errors; a live HelpfulError never reaches them.) it returns a deliberate body with a fixed label — `{ _serde, class: 'ConstraintError', message }` for a contemporary caller, `{ errorMessage, errorType: 'BadRequestError' }` for an ancient one — and the invocation succeeds, so no retry fires. the client reads that field. the label is the middleware's own constant, never a copy of `error.name`.

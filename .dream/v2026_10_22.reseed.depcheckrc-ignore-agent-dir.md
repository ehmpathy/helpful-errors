# 🌙 dream: depcheck must not scan `.agent/**`, and must ignore every rhachet brain

kind: reseed · owner: ehmpathy/declapract-typescript-ehmpathy · caught 2026-10-22

## .the cue that fired

5.3.verification of `v2026_10_22.fix-error-name-from-class`: `rhx git.repo.test --what lint` exits 2 locally, while ci's `test-lint` passes on #47.

## .the gap, precisely

`npx depcheck -c ./.depcheckrc.yml` reports, in this worktree:

```
Unused devDependencies
* rhachet-brains-openrouter
Missing dependencies
* claude-code: ./.agent/.actors/actor.via.repo=ambient/brain/.claude/plugins/…/code-modernization/tests/hostile.test.ts
```

1. `.depcheckrc.yml` `ignorePatterns` holds only `provision/**`. so depcheck walks `.agent/.actors/…`, a local actor dir that rhachet creates, and reads a plugin's test imports as repo deps. any repo with a local actor dir fails lint on that machine
2. `ignores` lists `rhachet-brains-anthropic`, `-xai`, `-fireworksai`, but not `rhachet-brains-openrouter`. the upgrade to rhachet 1.50 / bhrain 0.42 adds that devDep, and depcheck then flags it as unused
3. the jest configs (`jest.unit.config.ts`, `jest.acceptance.config.ts`) also collect test files under `.agent/`. `rmsafe` trashes a deleted test to `.agent/.cache/…/rmsafe/trash/<same path>`, gitignored, and jest then runs it: `FAIL .agent/.cache/repo=ehmpathy/role=mechanic/skill=rmsafe/trash/blackbox/zzprobe.acceptance.test.ts` · `Cannot find module '../dist/index'`. same for `.agent/.actors/…` plugin tests on `--thorough`

## .the shape of the fix

in the declapract-typescript-ehmpathy template for `.depcheckrc.yml`:

```yaml
ignorePatterns:
  - 'provision/**'
  - '.agent/**'
ignores:
  - rhachet-brains-*   # or list rhachet-brains-openrouter beside the other brains
```

and in each jest config template: `testPathIgnorePatterns: ['/node_modules/', '<rootDir>/.agent/']` (or narrow `roots` to `src` / `blackbox`).

check that depcheck 1.4.3 honors a glob in `ignores`. if it does not, list the package by name. then run `declapract.upgrade` downstream.
